# D36: a map's design follows the world's size

STATUS: DECIDED 2026-09-14 by Jafar, dictated and recorded by the resident.
Reaffirms D20 and adds the constraint today's work must not foreclose.

## The rule, as given

**No map markers and no fast travel for Phase A, as D20 rules.**

**The reason it is not built now is that a map's design follows the world's
size: a paper map at one square kilometre and a waypointed map across a
region are different objects, not one object bigger.**

## The constraint on today's work

**Nothing forecloses the larger one.**

1. **Places carry real coordinates and stable ids.**
2. **The Ledger records where a thing happened and not only that it did.**
3. **Any map is generated from that data rather than drawn.**

## When it reopens

**The question reopens when Phase B's region lands.** Per D20's own scope
clause, a later proposal is judged on whether the town has outgrown a
person's head, never on whether D20 can be overturned.
