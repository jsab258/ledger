# REUSE: what is method and what is 1990 or Meridian content, tool by tool

Written by unit 14, 13 October 2026, from the code. Each entry: what the tool does; the method another game could take as it is; this game's content baked into code, as file: constant or function; how hard the two are to pull apart. Easy: one table or a few constants. Medium: a few places. Hard: woven through the logic. Paths start at the repository root.

## tools/

**Gates on words, names and brands.** tools/canon-gate.py, tools/content-gate.py, tools/names-gate.py, tools/brand-verify.py, tools/slopcheck.py, tools/dialogue-verify.py. Refuse banned words, retired names and real brands in text, speech and prompts. Method: a word-boundary list gate, an exempt list, a --selftest that must refuse as well as accept. Content: tools/canon-gate.py: MODERNITY (mobile, internet, email); tools/content-gate.py: W, ASSET_BANNED (alcohol and gambling words), emitted to ledger/Assets/Scripts/Core/ContentWords.cs; tools/names-gate.py: RETIRED (Lena to Sheila and the rest); tools/brand-verify.py: KINDS; tools/dialogue-verify.py: NAMES. Separation: easy for the lists; medium for tools/content-gate.py (1,927 lines, rules and code together).

**Records, caps and guards.** tools/doc-caps.py, tools/catalogue.py, tools/homes_check.py, tools/approvals.py, tools/attribution-check.py, tools/branch_check.py, tools/git-size-guard.py, tools/push_guard.py, tools/retention.py, tools/timelog.py. Method: every rule gets a check that fails the build and says what it measured ("nothing measured" fails); an approval lapses with its source; a copy is compared with its home. Content: tools/doc-caps.py: CAPS (this project's document names); tools/catalogue.py: WATCHED; tools/approvals.py: IN_GAME; tools/attribution-check.py: NEVER_SHIP; tools/push_guard.py: MAP. tools/retention.py bakes drive paths (STATE is an F: path; its census names C:\LedgerTools and F:\LedgerTools); run on Linux its log landed in folders literally named F:\LedgerTools\retention, in the repository root and in production/cloud-week/kit/shop-windows, and its space check logged GO with no free space measured (an unmeasured drive counts as not short). Separation: easy.

**Pages for the owner.** tools/approval_page.py, tools/candidate_page.py, tools/day_page.py, tools/page_pictures.py, tools/make_preview.py, tools/morning_pictures.py. Method: one phone page, at most three one-line decisions, answers stored and read back; previews of 1600 px and 500 KB. Content: tools/make_preview.py: WIDTH, MAX_BYTES; tools/morning_pictures.py: VIEWS (this street's three cameras); each dated page script carries one day's cast and wording. Separation: easy for viewer and preview; medium for the dated pages.

**Game-code and port checks.** tools/lint-static.py (and seven more lints), tools/gamecheck.py, tools/port-golden-check.sh, tools/route_walk.py, tools/encounter-verdict-check.py, tools/talk-protocol-check.py. Compile and lint the C# layer; match the C++ port to the golden table; walk the route with real keys. Method: a reference emits the table; each lint names the compiler error it prevents. Content: tools/route_walk.py: LINE (a question to Sheila); the verdict checks name the window crime and its witnesses; the lints name the folders Core and Game. Separation: easy for the lints; medium for route and verdict checks (the story is in their logic).

**Frame and picture measurement.** tools/perf-hook.py, tools/frame-drift.py, tools/hook-pair.py, tools/ref-bench.py, tools/measure_night_pools.py, tools/frame-shadow-probe.py, tools/facade-pair.py. Method: numbers off the engine's CSV and the pixels, a --selftest on each, bands compared with a reference sheet. Content: tools/perf-hook.py: GPU_LINE_MS (a 14.0 ms budget line for this game); tools/ref-bench.py: GROUND_Y, FROZEN_SKY, FROZEN_ROAD (this game's frames); tools/frame-shadow-probe.py: SHOT_ID, CAM_ID; tools/hook-pair.py: REFERENCE (the Hook sheet). Separation: easy; medium for tools/ref-bench.py (frozen expectations in code).

**Talk samples and night jobs.** tools/first_token_sample.py, tools/talk_cost_sample.py, tools/nightly_walk.py, tools/nightly_package.py, tools/ai-tester/play.py. Sample the talk program with no real calls; walk the packaged game nightly. Method: a cost cap in code; one fixed command so approvals match; a commit-message flag asks for a build; a stale job fails the build. Content: tools/nightly_walk.py: TOWN (lena, rocco, sam to Sheila, Ron, Darren), NIGHT_ROOT; tools/nightly_package.py: FLAG, PLAYED_STAMP. Separation: easy.

**Blender recipes.** tools/art-recipes/. Build the street, a shop's room and props by script, headless. Method: tools/art-recipes/run-recipe.py runs a named recipe or refuses; tools/art-recipes/sash-window/target_drawing.py begins the worked pattern of target, build, check, review; tools/art-recipes/verify_display_sources.py traces each model to a source and licence. Content: tools/art-recipes/terrace-front.py (9,672 lines): STREET_FRONTAGE_M, LAMP_AT, STREET_BLOCKS, RAISED_LETTERS (Mickey's), 112 lines naming Mickey, Rita, Quay or a block; tools/art-recipes/shop-room.py (3,181 lines): the shops' rooms; tools/art-recipes/mickeys-props/ (eighteen props of a 1990 cab office, shared steps in tools/art-recipes/mickeys-props/_desk_common.py). Separation: hard for the street and room scripts (dimensions, trades and names in the logic); medium for the props; easy for the rest.

**Unreal editor scripts.** tools/ue/. Drive the editor by script: imports, materials, the cast's MetaHumans, run-time data. Method: every step repeats on a build machine; probes (tools/ue/face_coeffs.py, tools/ue/preset_facts.py) list what the API offers first. Content: tools/ue/make_cast_metahumans.py: CAST, CASTING, CANDIDATES (every attempt at every face kept as a dict, named TOM and SHEILA); tools/hdr-to-longlat.py: APPROVED (the sky photograph). Separation: easy for the import scripts (a list names the files); medium for tools/ue/make_cast_metahumans.py (1,532 lines of per-person tables and attempt history).

**Props, clothes and hair.** tools/meshgen/, tools/md/. Licence-gated props; garments sewn, fitted, skinned and posed. Method: tools/meshgen/meshgen.py refuses a tool whose weights licence is not allowlisted (BANNED, SOURCE_LICENCES_OK, ALLOWLIST_DOC); tools/meshgen/blender/pose_test.py tests arms down, arms up, walking, sitting; tools/meshgen/blender/bind_garment.py binds panel by panel. Content: tools/meshgen/blender/clutter/kx100_kiosk.py, tools/meshgen/blender/clutter/pillar_box.py (1990 British objects at real size); tools/meshgen/blender/model_cardigan.py; tools/meshgen/blender/sew_donkey.py (Ron's jacket). Separation: easy for the licence gate and pose tests; medium for clothes (the garment is the content; routes stopped, RULINGS.md).

**Voice.** tools/voice-live/, tools/voice-gen/, tools/voice-fetch/. Speak the cast, time each stage from line to first sound, gate takes by accent. Method: tools/voice-live/latency.py times every stage on the real runtime; tools/voice-live/take_gate.py reads 2.5 s windows, words and likeness; tools/voice-live/precompute-voices.py computes each voice once. Content: tools/voice-live/accent_check.py: AMERICAN, REJECT_AT (a British-English target); tools/voice-live/voice-server.py: CAST; tools/voice-live/latency.py: LINES; tools/voice-fetch/voice_bank.py: CAST, POOL_MASCULINE, POOL_FEMININE. Separation: easy for the timing; medium for the gates. The 2 s delay was not met.

**Other fetchers and makers.** tools/mixamo-pick/pick_animations.py, tools/props/fetch_vignette.py, tools/citypack/fetch_textures.py, tools/imagegen/imagegen.py, tools/ui/make_paper.py. Pick clips, fetch CC0 assets, make portraits, draw an interface. Method: clip names do not match motions, so profile the motion (tools/meshgen/blender/sitting_clips.py). Content: tools/ui/make_paper.py (the evening paper's look); tools/imagegen/make_casting_spec.py (the cast's portraits); tools/props/make_office_print.py (Mickey's printed matter). Separation: easy to medium.

**Hooks, launchers and benchmarks.** tools/hooks/pre-commit, tools/blender-live/live_piece.py, tools/tts-benchmark/ledger_tts_bench.py, tools/play/, tools/friends/evening.ps1, tools/runner/reconnect.ps1. Hooks run the size guard and caps; a helper makes clutter live in Blender; one file benchmarks voices. Content: tools/blender-live/live_piece.py: PROMPT (a northern English town in 1990); tools/tts-benchmark/ledger_tts_bench.py: VOICES, FEMALE (old cast ids). The launchers are not established beyond their names. Separation: easy.

## ledger/

**The C# Core and its test programs.** Simulates the town, the talk's checks, the save and the content rule. Method: ledger/PerceptionGolden/Program.cs emits the golden table a port must match; ledger/Soak/Program.cs runs a world very long, twice; ledger/SaveChaos/Program.cs fuzzes damaged saves; ledger/StrangerTest/Program.cs plays one crime twice with one change; ledger/Assets/Scripts/Core/ClaimCheck.cs lets a character say only what the simulation knows; ledger/Assets/Scripts/Core/ContentRule.cs makes a crowd generator unable to make a child. Content: Soak and SaveChaos name none of Ron, Sheila, Mickey or Quay; ledger/CoreTests/Program.cs names Ron on 136 lines, Mickey 127, Sheila 70; each of the three is in 21 to 29 of the 135 Core files; ledger/Assets/Scripts/Core/HookMap.cs (Meridian's places), ledger/Assets/Scripts/Core/CastDay.cs, ledger/Assets/Scripts/Core/RealWorld.cs (real names refused, 1988 to 1992). Separation: easy for the test design; hard for rules woven with canon's people (ledger/Assets/Scripts/Core/Gossip.cs, ledger/Assets/Scripts/Core/PoliceFile.cs).

## production/cloud-week/

**Kit pieces.** production/cloud-week/kit/ (not shop-windows). Build one street object by script from its target's numbers and check it. Method: production/cloud-week/kit/BUILD-BRIEF.md (a number the target lacks is a fault in the target; pass rule IoU 0.97, outline p95 2 mm, dimensions within 1 mm); production/cloud-week/kit/tools/outline.py, production/cloud-week/kit/tools/joinery.py; production/cloud-week/kit/tools/review_render.py (four views, grey sky, eye at 1.6 m). Content: production/cloud-week/kit/door/build_door.py: VARIANT_KEY, DEFAULT_PAINT; production/cloud-week/kit/shopfront/build_shopfront.py: PARTS; production/cloud-week/kit/pillar-box/build_pillarbox.py: Z_ROLL, R_RIM; production/cloud-week/kit/bins/build_bins.py: BURN_AZ, BIN_OFFSET; production/cloud-week/kit/tools/review_render.py: default_views. The helpers merge, volume and orient are copied in production/cloud-week/kit/bins/build_bins.py, production/cloud-week/kit/kerbs-covers/build_kerbs.py and production/cloud-week/kit/lamp-posts/build_lamp.py, not shared. Separation: easy for the shared tools; medium for each build script.

**Targets: method and shared checks.** production/cloud-week/targets/. Write an exact target from dated photographs and test it before building. Content: production/cloud-week/targets/BRIEF.md (the game paragraph and the content rules); production/cloud-week/targets/street-dressing/sd_place.py: STREET_X, FOOTWAY_Z, WALKER_W_M, ZONES; production/cloud-week/targets/street-dressing/sd_check.py: CONTENT_WORDS. Copied, not shared: production/cloud-week/targets/street-dressing/sd_lib.py: BLOCKLIST, production/cloud-week/targets/front-doors-all/td_common.py: BLOCKLIST, production/cloud-week/targets/house-windows/hw_data.py: BRAND_BLOCKLIST, production/cloud-week/targets/shop-windows/make_target.py: BRAND_BLOCKLIST; ALLOWED_LICENCES differs between production/cloud-week/targets/street-dressing/sd_check.py (nine) and production/cloud-week/targets/front-doors-all/self_check.py (five). **Targets for doors, windows and street dressing.** production/cloud-week/targets/front-doors-all/, production/cloud-week/targets/house-windows/, production/cloud-week/targets/street-dressing/, production/cloud-week/targets/shop-windows/. Numbers for ten door kinds, twenty windows, nine street objects, ten shop units. Method: derive each position live from the street's generator (production/cloud-week/targets/front-doors-all/td_sites.py, production/cloud-week/targets/house-windows/hw_sites.py), never from memory; mark each number Photo, Read or Judgement with its error; import the game's projection rule (production/cloud-week/targets/shop-windows/sw_common.py), never rewrite it. Content: production/cloud-week/targets/front-doors-all/td_data.py: PALETTE, HOUSE_CHOICES; production/cloud-week/targets/house-windows/hw_data.py: PAINTS, NETS, LIT_SHARE; production/cloud-week/targets/house-windows/hw_rooms.py: ROOMS; production/cloud-week/targets/shop-windows/sw_shops.py: SHOPS; production/cloud-week/targets/street-dressing/skip/target.json (the 1984 skip marking rules). **2D makers.** production/cloud-week/2d/fascias/, production/cloud-week/2d/paper/, production/cloud-week/2d/wear/. Draw boards, posters, plates and 33 kinds of wear mask from a target and a seed. Method: same seed, same pixels, verified against a SHA-256 manifest; a check with wrong pictures it must refuse and a reader independent of the maker (production/cloud-week/2d/paper/paper_reader.py); a crashed item is a failing row. Content: production/cloud-week/2d/fascias/fascia_common.py: FONT_FILES, HOOK_CAST; production/cloud-week/2d/fascias/fascia_wear.py: RUST, CHALK_DUST; production/cloud-week/2d/paper/paper_common.py: AGE, CLASSES; production/cloud-week/2d/paper/paper_wear.py: LIME (gull lime); production/cloud-week/2d/wear/make_wear.py: EDGE_KINDS; shop names and boards sit in each target's target.json. Separation: medium; shapes are generic functions, palettes and kinds constants; production/cloud-week/2d/wear/wear_departures.py replaces the target's shapes in code (hard).
