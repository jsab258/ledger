# TOWN: the simulation's and talk's bounded tasks

Since 5 October one production session hands town work out as bounded tasks (CLAUDE.md, PLAN.md): each with its versioned inputs (the commit and files it starts from), its acceptance cases and a ceiling; the session checks the result before it lands. No lane of its own, no list of its own; the old list is in production/archive/2026-10-05-retired/TOWN.md.

Every task: a failing test first; CoreTests, Soak, SaveChaos, PerceptionGolden, StrangerTest and a regression test pass; the Unreal port matches the C# goldens; never Unreal, art, voices or the graphics card. Every run that can spend on LEDGER's key estimates its cost first and stops at the day's dollar (enforced in code).
