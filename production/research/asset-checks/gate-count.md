## Counting rule, as applied
- **Piece:** one gate record's subject, or one cloud-week kit item. The 21 October found-list is a list; only its one gated item (Mickey's glass words) counts as a piece.
- **Round:** each block of views photographed or re-photographed for reviewers, as labelled (Round N, rN, wN, re-shoots, "close views again", a new day's or a ruling's try). Labelled rounds marked "measured, not reviewed" still count; the reviewed count is in brackets.
- **Review:** one reviewer's verdict on one view in one round. Cloud-week reviews are bundled, one reviewer per view of 4 to 5 frames, so they count reviewers.
- **First full pass:** the block after which every view stood passed, with set-aside faults listed.
- **FAILs:** an overruled FAIL (a known shortfall) still counts.
- **M/L/P:** distinct faults per round, so they need not sum to FAILs. A missed re-import is M; a cloud stand-in render fault is P.
