## 5. Post-mortems and devlogs (all small or non-story; none is a 3D crime RPG)
### Project Aegis (mobile merge/tower-defence, Unity 6)
- Daniel Steegmuller, 17 Mar 2026, https://cxyda.github.io/ProjectAegisDevLog. Claude Code (Opus) + UnityMCP, ADRs + CLAUDE.md, Planner/Challenger plan debate, quality-gate skill. Solo feasibility test: no hand code, no Editor clicks.
- Scale/time: 328 C# files, 42,628 lines, 589 tests; ~20-22 hours wall-clock over 8 milestones, 309 sessions, 20 days. Cost: not found.
- Art/story: not covered.
- Went wrong: Claude silently dropped features (hero abilities, auto-engagement); fixed symptoms not root causes; context rot with large work packages; ECS/Burst harder; save state incomplete because spec omitted it; author's growing dependence.
- Lessons: layered assemblies and architecture help; UI Toolkit (text) far easier than uGUI; plan then diff implementation against plan; automated quality gates; Opus preferred over Sonnet for scope discipline; one phase per session.
- Quality evidence: self-reported only.
### Manasight (MTG Arena companion, not a game)
- Solo, 51 days, ~80,000 lines, 616 merged PRs, ~6,590 tests, test code 144% of production (https://dev.to/manasightgg/80000-lines-of-code-in-51-days-2a3, posted 29 Mar, year not shown).
- Workflow: specified issues under ~200 lines, fresh-context reviewer agent on each diff, five parallel review agents with confidence threshold, CI green gate, CLAUDE.md pre-commit checks.
- Went wrong: parallel agents on stale context compounded errors and merges. Lesson: human review/QA is the long pole.
### Robot Battle rebuild (browser, Claude Opus 4.6 agent teams)
- https://tgvashworth.substack.com/p/how-i-rebuilt-a-game-from-my-childhood (11 Feb 2026). 77 sub-agents, one Sunday plus ~2 evenings, 647 tests, ~11k source and 22k test lines, Docker sandbox, browser-tester agent.
- Went wrong: SawBot ~7 rewrites, WallBot 3 (trig/heading errors); radar bug; codegen scope bug found by property-based tests, not hand-written tests.
- Lessons: goal-oriented prompts beat over-specified ones; interface specs before code; always-working milestones; running the game found bugs tests missed.
### Spell Cascade 5-agent studio (Claude Code Agent Teams, Opus 4.6)
- https://dev.to/yurukusa/i-ran-a-5-agent-game-studio-with-claude-code-teams-2lpk (posted 19 Feb, year not shown). 9 of 17 tasks done; results weak (0 Gumroad sales, 201 views, itch 3.8% download rate). Went wrong: idle blocked agents, duplicated context, all-Opus cost, designer work invalidated by late builder changes. Lessons: explicit dependencies, role boundaries, cheaper models for light tasks.
### Shin KoiKoi (Godot 4.6 C#, card game)
- https://dev.to/morinaga/i-shipped-a-polished-hanafuda-card-game-in-2-days-with-claude-and-godot-5a7j (release 2 May 2026). ~3 weeks design pre-work, 2 days build, 1 polish day; 184 tests; ~45 images via Gemini and Midjourney disclosed; art avoids people to reduce IP risk. Went wrong: macOS export (VRAM compression), font order, Linux permissions found late. Lessons: automate screenshots early, smoke-test every platform, firm scope. Claude ~70% of UI scaffolding.
### Web game in 48 hours (Claude Opus 4.7)
- https://dev.to/pickuma/building-addictive-web-games-with-claude-opus-47-a-2-day-solo-dev-case-study-24ao ("early 2026").
