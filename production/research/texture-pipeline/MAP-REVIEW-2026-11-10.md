# Review of MAP-2026-11-10 against advisor 88 and notes A, B, C (10 November 2026)

**Verdict: FIX.** All four chains match the brief, the six measures are all planned, and most numbers agree with their sources. Before the first run, the map needs a memory cost for each source, an end section that leads to the verdict, a correct reason for the third try, and a way of measuring memory that can pick up the sizes involved.

Arithmetic, recomputed: a 2K set (BC7 colour, BC5 normal, BC1 mask, mips x1.333) is 5.33 + 5.33 + 2.67 = 13.3 MiB, about 14 MB. A 4K set is 53.3 MiB, about 56 MB. A 1K BC1 mask is 0.67 MiB, about 0.7 MB. All three are right. B's 10.7 and 42.7 MiB assume BC1 colour, which is what Unreal uses by default for opaque colour. C and 4-BUDGETS §4.7 assume BC7. The map's claims rest on BC7, which is the right basis because it is the budget's home and the more cautious figure. Line 22 should say so.
