## 1. hython / hbatch / Python with an Apprentice licence

- SideFX docs, licensing/system page (read 2026-11-11): hython has a separate Apprentice licence list holding only Apprentice; `--skip-license-modes` / `--check-license-modes` accept `apprentice`; env var `HOUDINI_HYTHON_LIC_OPT` also applies to hbatch. https://www.sidefx.com/docs/houdini/licensing/system.html
- SideFX staff (mchaput), 18 Feb 2020: hython runs with an Apprentice licence if it only reads information and does not save a HIP file or asset. Old thread, outdated by years. https://www.sidefx.com/forum/topic/72052
- Houdini hython page (read 2026-11-11): says nothing about Apprentice. https://www.sidefx.com/docs/houdini/hom/commandline.html
- Search result only, unverified: a SideFX developer said an Apprentice licence cannot be installed from the command line; headless/server use is "not how Apprentice was intended".
- Python inside the GUI: no restriction found in any page read. Unverified for 21/22.
- Whether hython in 21/22 can save or export under Apprentice: unverified (the staff answer above suggests no saving).

## 7. Cascadeur Free plan

- Plans page (read 2026-11-11): Free is "300 frames per scene", "120 joints per scene", export CASC only (".fbx and .dae are not available"), "Only non-commercial use". https://cascadeur.com/plans

## 8. Cascadeur Python API

- Python 3.8; Python console in the Window menu; custom commands as .py files in the commands folder with `command_name()` and `run(scene)`. https://cascadeur.com/help/tools/animation_tools/python_scripting_in_cascadeur
- API has an app-level `csc.app.Application` with Tools Manager, View and Fbx components, plus Scene-level interfaces. https://cascadeur.com/help/category/215 ; reference https://cascadeur.com/python-api
- 2026.2 release "expands Cascadeur's Python API". Licensing FAQ link above.
- Headless / command-line / batch mode: not documented in any page read. Python on the Free plan: not stated. Both unverified. Whether AutoPhysics is scriptable: not found.

## 10. MetaHuman skeleton FBX in Cascadeur

- Cascadeur help, read 2026-11-11: export MetaHuman from Quixel Bridge (Maya target, not LOD0) or from Unreal Asset Actions > Export; File > Import Fbx/Dae > Scene for one skeleton mesh; further meshes need root Transform renamed to match, then Add model to selected; then the Quick Rigging Tool (MetaHuman skeleton "similar to the standard UE4 and UE5 models"). https://cascadeur.com/help/category/210
- Before export: FbxUpAxis = Z, TypeFbxAscii = Off; export Without Meshes. Known issue: distortion in Unreal fixed by setting root and pelvis to Animation, others to Skeleton in the Unreal skeleton. The page says MetaHumans export only to Maya and Unreal.
- Cascadeur's Unreal export guide (search result only): binary FBX, Import Only Animations. https://cascadeur.com/help/export_to_unreal_engine
