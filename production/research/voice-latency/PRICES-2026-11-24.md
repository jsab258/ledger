Notes from P:
- Sonnet 5: footnote 3 says the $2/$10 pricing, announced at launch as introductory through 31 Aug 2026, is now standard; the scheduled rise to $3/$15 on 1 Sep 2026 will not occur.
- Sonnet 5.5: cache hits priced at 0.05x base input (footnote 2). All other listed models here use 0.1x.

## Q3. Batch and caching discounts (source P, 24 Nov 2026)
- Batch API: "50 percent discount on both input and output tokens". Batch rates listed: Haiku 4.5 $0.50 in / $2.50 out; Haiku 5.5 up to 100k tokens $0.05 / $0.25, over 100k $0.25 / $1.25; Sonnet 5 $1 / $5; Sonnet 5.5 $1 / $5.
- Prompt caching multipliers on base input: 5-minute write 1.25x; 1-hour write 2x; cache read 0.1x on most models, 0.05x on Sonnet 5.5 and Opus 5.5 (0.025x on Fable/Mythos 5.1 and 5.2). 5-minute caching saves money after one read, 1-hour after two reads.
- P states "Batch API and prompt caching discounts can be combined" and that caching multipliers stack with the Batch API discount and data residency.
- Other modifiers on P: US-only inference (inference_geo "us") is a 1.1x multiplier on Claude 4.6 and later models (applies to Haiku 5.5 long-context prices too); not available on models earlier than 4.6 (so not Haiku 4.5). Fast mode is not offered for these four models and is not available with batch.
- Tool use adds system-prompt tokens (Haiku 4.5 496; Haiku 5.5 286; Sonnet 5 354; Sonnet 5.5 286 with auto/none).
