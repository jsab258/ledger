# Baseline brief: stakes only (a control, not the judge)

Added 23 November after half A passed, before half B or the baseline ran. If a judge asked only "which scene has more at stake" scores as well as the full brief, the full brief is not measuring craft beyond stakes and spectacle. Run by fresh Sonnet on half A, both orders.

---

Each scene below is a retelling of one scene from a story-driven game, in a fixed plain format. For each pair, say only which scene has more at stake for the people in it: more danger, more loss, higher consequences. Do not judge quality, writing, characters or how memorable it is; only the size of the stakes. One must be chosen.

For each pair answer in one line of JSON: {"pair": "<pair id>", "choice": "1" or "2", "reason": "<at most 10 words>"}.
