# Prototype against the real game's rules (18 Nov 2026)

On 17 November the owner made the browser prototype the whole game in rough form and the spec of record, with one simulation: the C# Core in the browser if it works, else rules that pass the same golden answers (DECISIONS.md, 17 Nov 22:38). So the two sides must agree. This note checks each disagreement found in the hand reading of the prototype (PROTOTYPE-RULES-READ-2026-11-18.md) against the C# Core code, the Unreal port and the design documents, and adds the ones found on the way.

How each row was settled: canon first; then the owner's rulings; then his 17 Nov "one simulation" clause, which means a rule that already lives in the C# Core (proven by 102,953 golden rows matched by the port on 18 Nov) comes from the Core, while what the Core does not have (fares, jobs, rent, the clock, the week's shape) comes from the prototype, which has the playtest feel. Where the choice changes how the game feels and no ruling settles it, it goes to him.

Limits: the prototype side is a hand reading of a minified bundle, unverified until Fable's source arrives. The C# side was read in the code on 18 Nov; nothing in the Core was edited. How many golden rows each change would re-take was not measured; rows below say which kind.

## Three decisions for the owner

1. How long is a game hour? A: 45 real seconds, as the prototype plays (recommended). B: 30 seconds, as the Unreal clock runs now.
2. How far does a story travel? A: the real game's rule, about one retelling along friendships, fading over four days, and if the street feels quiet, make the people who heard show it more (recommended). B: the prototype's, several retellings between any neighbours, fading in about a day.
3. Should each person have their own temperament (nerve, loyalty, how talkative, how discreet)? A: yes, from the prototype's numbers and the 29 September draft, measured before it lands (recommended). B: everyone stays ordinary for now.

Decisions 1 and 2 pull against each other: the first-hour bar was measured with the 30-second hour and the one-retelling rule, with 7 of 13 runs landing only at minute 30, so taking A on both needs that measurement re-run first.

Everything else above is the builder's call: rows 2, 3, 8 to 18, each recorded in DECISIONS.md when acted on.
