# Combat and stealth test: results

Tested 25 Nov 2026 against COMBAT-SYSTEM.md (CS-01 to CS-26), the blueprint parts it keeps (1.4, 1.5, RT2-13, RT2-14) and LONG-HEAT.md. Judged independently; the old verdicts were compared only afterwards.

## Counts

- Old set (126 questions): 116 combat questions; answered 42, weak 68, unanswered 6, not-combat 10; unanswered 5.2%, unanswered plus weak 63.8%.
- Old set, against the old verdicts: 29 moved from UNANSWERED or WEAK to ANSWERED (Q001, Q002, Q003, Q004, Q006, Q008, Q013, Q015, Q022, Q025, Q026, Q073, Q087, Q092, Q096, Q108, Q111, Q120, Q124, Q126, Q127, Q132, Q135, Q160, Q161, Q165, Q200, Q206, Q213). For the same combat questions the old test had WELL 19, WEAK 91, UNANSWERED 6. 6 that the old test called WELL are now WEAK or UNANSWERED (Q030, Q031, Q117, Q125, Q133, Q153), mostly because the new rules no longer cover them (guns pending, the inquiry into a civilian killing, Darren's tips, a carry limit).
- Fresh set (30 questions): 30 combat questions; answered 6, weak 18, unanswered 6, not-combat 0; unanswered 20.0%, unanswered plus weak 80.0%.
- Fresh set, stealth questions only (N01 to N10): answered 2, weak 5, unanswered 3.

Not-combat (old set): Q020, Q033, Q034, Q035, Q036, Q040, Q041, Q091, Q155, Q171 (police talk, bribery, blackmail, planting evidence, tip-offs, staff, fares, debts).
