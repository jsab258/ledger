# METHOD: how this system pass ran, for Monday's other passes

25 Nov 2026, the combat and stealth pass. What worked, what did not, in order.

1. Census before design, in parallel: two Sonnet web readers (games split by kind) and one Sonnet reader of the project's own files, about 5 minutes each; a Sonnet merger deduplicated 393 rows to 337. Worked well and cheaply. The merger needs the readers' paths exactly (one file landed in the wrong folder).
2. A blind list written at the same time as the census, by a fresh Opus that sees nothing; a separate fresh Opus compares strictly. Worked: it found 27% missing, mostly the things a project's own players would try. Run it again after design: the second list still found 19% (hard misses 6%). Next time: run the blind check per heading (stealth, police, feel) rather than once for all; the misses hide where a broad row stands in for many questions.
3. The simulator before the design text, so the text quotes the code. Tuning took about eight short rounds; the knobs that mattered were the wind costs and when wind returns (mashing), the townspeople's attack rate, the yield and flee thresholds, and the knock-down chance. Keep a decided-only win rate beside the raw one, or stopped fights hide losses.
4. A fresh reviewer on the design and the code together, with the rulings and the research. Worth it: it found the fight ending at the first knock-down, a beaten Frank not counted as lost, finishing with a weapon doing nothing, the shove killing against his fists line, takedowns as listed tables, Frank having moves others lacked, and a quiet change to his hospital bill. Give the reviewer the right to run the code.
5. Outside questions judged by a fresh tester, then the design revised, then judged again; and finally a clean set from a new writer and a new tester with no revision after. Only the clean set is an honest measure; say so.
6. Census rows mapped to the design by a strict Sonnet mapper (GAP where the text does not say it), re-run after revision; the designer closes the last gaps and says which ones the mapper did not re-check.
7. Cost: 4 Sonnet readers, 1 Sonnet merger, 1 Sonnet mapper (twice), 8 fresh Opus helpers (two blind lists, two comparers, two question writers, two testers counting the re-judge, one reviewer, plus the final reviewer). About three hours.
8. What to copy: wishes first, then general rules (one body rule, one temper rule, one perception rule), each part with How it works, Standard, Test, Source, Status, and an Out list with reasons; a Kept list naming blueprint parts so the mapper can find them; RULINGS-TO-REVISIT for anything that argues with him, never a silent change.
