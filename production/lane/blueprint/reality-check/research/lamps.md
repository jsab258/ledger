# Street lamp column spacing, Britain 1988-1992 (research, 24 Nov 2026)

Method: web search plus page fetch from the cloud sandbox. Fetch tool returns a model summary of the page text, not the raw page; images cannot be viewed. "READ" = fetched and read today. "SNIPPET" = only seen as a search-result title.

## Result in one line
No source reached gives a 1988-92 column spacing in metres for terraced side streets. The best-supported number is the 1977 BS 5489-3 design spacing for residential roads (group B5/6): 34 m +/-10 % (about 31 to 37 m), via a modern secondary source. The 1989 Part 3 stopped specifying spacing and set illuminance classes instead. Everything else below is inferred or unreached.

## Period facts (standards in force 1988-92)
1. BS 5489-3:1977 (superseded by 1989 edition). Groups B8 (district roads) and B5/6 (residential; the number is mounting height in m, so 5 to 6 m). B5/6 target spacing 34 m +/-10 %; B8 spacing varied with road width. Source: Fotios and Robbins, "Describing average illuminance for P-class roads", Lighting Research and Technology, 2020, https://eprints.whiterose.ac.uk/id/eprint/158459/10/1477153520911193.pdf - READ today. Modern paper describing the 1977 code; secondary, not the code itself.
2. BS 5489-3:1989 (published 1989; BSI record says withdrawn 11 Dec 2003; BSI page also shows 15 Aug 1992 date, likely an amended reprint: inferred). Replaced the 1977 edition. Performance-based: classes S1, 3/1, 3/2, 3/3 with average and minimum illuminance (example given: S1 15.0 lx avg / 5.0 lx min; other values not captured). The 1992 edition kept these classes. Same Fotios paper (READ) plus https://trid.trb.org/View/352454 (READ, 1989, record created Feb 1991) and https://knowledge.bsigroup.com/products/road-lighting-code-of-practice-for-lighting-for-subsidiary-roads-and-associated-pedestrian-areas (READ; no figures on the page). Spacing-to-height ratios for 3/1-3/3: NOT FOUND. The code text is paywalled and was not reached.
3. DTp TD 30/87 (Nov 1987) "Design of road lighting for all-purpose trunk roads": https://www.standardsforhighways.co.uk/tses/attachments/e38dbefb-2271-46c1-a27f-0b1a1be3027c - READ. Gives no spacing ratio, no stagger/opposite rule, no bend or junction rule; defers to BS 5489 Part 2, and to Part 4 for junctions. So it does not answer the through-road question.
4. BS 5489 Part 2 (traffic routes), Part 4 (junctions): titles only, SNIPPET (BSI listings). Content unreached.
5. SOX re-rated wattages 35, 55, 90, 135, 180 W (tin-indium oxide coating, Philips 1966, marketed about 1968); earlier 40/60/100/150 W from 1964. https://www.lamptech.co.uk/Documents/SO%20SOX.htm - READ. Lamp data, not street use.
6. Last concrete columns installed in the UK in the early 1990s; first in the 1930s; Stanton types common 1950s-60s. https://www.simoncornwell.com/lighting/install/concrete1/index.htm - READ (hobbyist site, undated, no spacing or heights given).
7. Philips SXK55 (35-55 W SOX, early 1970s-late 1980s) was a security/yard lantern, not a street one: https://www.simoncornwell.com/lighting/collect/lanterns/philips-sxk55-1/index.htm - READ. Not evidence for street wattage.
