# 50 things in LEDGER: the video list (24 Nov 2026)

What a "50 incredible details in LEDGER" video would show from the first ten hours, picked by the lead from about 290 candidates that four readers drew from the blueprint on lane-2026-11 (chapters 01 to 11, data/, temper/, ai-brain/, what-if/, reality-check/). Each line: the detail as such videos say it; the parts that back it; status; whether a catalogue game has it (the seven games and his GTA VI video in the details catalogue on wip) or it is LEDGER's own; and, if not designed, whether closing it changes how the game is built (BUILD: a system, rule or data structure the code must have; must close before the one-shot) or only adds content (CONTENT: left to the loops).

Status: designed = rules and exact numbers or data in the blueprint, so a builder need not invent; partly = words only, or a number or data missing, or in conflict; missing = the wish is named but there is no design. "First values" means the numbers are exact but unmeasured (the reality check's point stands: exact is not the same as right).

Unique: "LEDGER's own" means none of the catalogue's games shows it in the notes; "also in" names the game; "nearest" names a game with a weaker form.
